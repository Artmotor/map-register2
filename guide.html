1 Регистрация и подтверждение почты Registration & Email Verification
  1. На главном экране в правой колонке заполните форму регистрации
  2. Имя — ваше имя или название организации
  3. Email — действующий email (на него придет письмо)
  4. Пароль — минимум 6 символов (рекомендуется 8+)
  5. Нажмите «Создать аккаунт»
  6. Откройте письмо от Firebase и подтвердите email
  1. Fill out the registration form in the right column on the main screen
  2. Name — your name or organization name
  3. Email — valid email (a confirmation letter will be sent)
  4. Password — minimum 6 characters (8+ recommended)
  5. Click “Create account”
  6. Open the email from Firebase and verify your email
Совет: Без подтверждения email вход невозможен! Проверьте папку «Спам», если письмо не пришло. Tip: Login is impossible without email verification! Check your Spam folder if the email hasn't arrived.

2 Вход в систему Login to the system
  1. На главном экране в левой колонке заполните поля входа
  2. Введите подтвержденный Email и Пароль
  3. Нажмите «Войти»
  4. После входа откроется Личный кабинет
  1. Fill out the login fields in the left column on the main screen
  2. Enter your verified Email and Password
  3. Click “Login”
  4. After login, the Dashboard will open
Кнопка «Личный кабинет» всегда доступна в правом нижнем углу экрана. The “Dashboard” button is always available in the bottom-right corner.

3 Создание гео-зоны доступа Creating a geo-zone
  1. В личном кабинете перейдите на вкладку «Создать зону»
  2. Заполните форму:
    • Название зоны — например, «Вход на конференцию»
    • Широта / Долгота — можно выбрать на карте (кнопка ниже)
    • Радиус — разрешенное расстояние от точки (метры)
    • Ссылка на форму — куда попадет пользователь после проверки
    • Описание — дополнительная информация (необязательно)
  3. Нажмите «📍 Выбрать на Яндекс.Карте» — откроется карта для точного выбора координат
  4. Нажмите «Создать зону»
  1. In the dashboard, go to the “Create zone” tab
  2. Fill out the form:
    • Zone name — e.g., “Conference entrance”
    • Latitude / Longitude — can be selected on the map (button below)
    • Radius — allowed distance from the point (meters)
    • Form link — where the user will be redirected after verification
    • Description — additional information (optional)
  3. Click “📍 Select on Yandex Map” — the map will open for precise coordinate selection
  4. Click “Create zone”
Удобный способ выбора координат: кликните на карте или перетащите метку — координаты подставятся автоматически. Convenient coordinate selection: click on the map or drag the marker — coordinates will be filled automatically.

6 Как проходит гео-проверка у пользователя How geo-verification works for users
  1. Пользователь переходит по ссылке или сканирует QR
  2. Открывается страница с названием зоны и кнопкой проверки
  3. Пользователь нажимает «Подтвердить местоположение»
  4. Браузер запрашивает разрешение на геолокацию — нужно нажать «Разрешить»
  5. Система проверяет расстояние до зоны
  6. Если пользователь в радиусе → перенаправление на форму
  7. Если вне радиуса → сообщение с указанием расстояния
  1. User clicks the link or scans the QR code
  2. A page opens with the zone name and verification button
  3. User clicks “Verify location”
  4. The browser asks for geolocation permission — click “Allow”
  5. The system checks the distance to the zone
  6. If user is within radius → redirected to the form
  7. If outside radius → error message with distance
Результаты проверки: Verification results:
  • ✅ В радиусе — доступ открыт
  • ❌ Вне радиуса — доступ запрещен
  • ⚠️ Запретил геолокацию — просьба разрешить
  • ⏸️ Зона неактивна — сообщение о недоступности
  • ✅ Within radius — access granted
  • ❌ Outside radius — access denied
  • ⚠️ Geolocation denied — request to allow
  • ⏸️ Zone inactive — message about unavailability
Статистика в карточке зоны: Statistics in zone card:
  • Visits — сколько раз переходили по ссылке
  • Successful checks — сколько успешно прошли проверку
  • Visits — how many times the link was opened
  • Successful checks — how many successfully passed verification

Частые вопросыFrequently Asked Questions

📧 Не приходит письмо с подтверждением email?📧 Didn't receive the email verification?
Проверьте папку «Спам» или «Promotions». Подождите 2-3 минуты. Убедитесь, что ввели верный email. Если письмо не пришло — попробуйте зарегистрироваться с другим email или запросите повторную отправку через Firebase.Check your Spam or Promotions folder. Wait 2-3 minutes. Make sure you entered the correct email. If the email hasn't arrived — try registering with a different email or request a resend via Firebase.
📍 Геолокация не работает / низкая точность?📍 Geolocation not working / low accuracy?
На смартфоне: включите GPS и разрешите доступ к геолокации в браузере. На компьютере: разрешите доступ в настройках браузера (значок замка в адресной строке). Для лучшей точности используйте мобильное устройство с GPS на открытом пространстве.On smartphone: enable GPS and allow geolocation access in your browser. On computer: allow access in browser settings (padlock icon in address bar). For better accuracy, use a mobile device with GPS in an open area.
📍 Пользователь говорит, что на месте, но проверка не проходит?📍 User claims to be at the location but verification fails?
Возможные причины: радиус зоны слишком маленький (увеличьте до 50-100 м), координаты зоны указаны неточно (проверьте на карте), у пользователя низкая точность GPS (в помещении или облачная погода), пользователь запретил геолокацию в браузере.Possible reasons: zone radius is too small (increase to 50-100 m), zone coordinates are inaccurate (check on map), user has low GPS accuracy (indoors or cloudy weather), user denied geolocation in browser.
🔒 Безопасно ли хранить данные?🔒 Is it safe to store data?
Да, все данные хранятся в защищенной Firebase (Google). Пароли шифруются и не передаются в открытом виде. Используется HTTPS-соединение. Сервис соответствует базовым стандартам безопасности веб-приложений.Yes, all data is stored in secure Firebase (Google). Passwords are encrypted and never transmitted in plain text. HTTPS connection is used. The service meets basic web application security standards.
📊 Как просмотреть статистику по зоне?📊 How to view zone statistics?
Статистика отображается в карточке каждой зоны в разделе «Мои зоны»: 👁️ Visits — количество переходов по ссылке, ✓ Successful checks — количество успешных гео-проверок. Данные обновляются в реальном времени.Statistics are displayed on each zone card in the “My zones” section: 👁️ Visits — number of link opens, ✓ Successful checks — number of successful geo-verifications. Data updates in real time.
🔁 Можно ли восстановить удаленную зону?🔁 Can I restore a deleted zone?
Нет, удаление зоны безвозвратно. Данные о посещениях и успешных проверках также теряются. Рекомендуем вместо удаления использовать кнопку «Отключить» (⏸️) — зона станет недоступной для пользователей, но все данные сохранятся, и вы сможете включить её позже.No, zone deletion is permanent. Visit and success data is also lost. Instead of deleting, use the “Disable” button (⏸️) — the zone will be unavailable to users, but all data will be preserved, and you can re-enable it later.
🌐 Какой радиус лучше выбрать?🌐 What radius should I choose?
Для входа в здание достаточно 20-50 метров. Для парковки или открытой территории — 100-200 метров. Для больших мероприятий (фестиваль, стадион) — 300-500 метров. Не делайте радиус слишком маленьким (менее 10 м) — GPS может ошибаться на 15-20 метров.For building entrance: 20-50 meters is enough. For parking lots or open areas: 100-200 meters. For large events (festival, stadium): 300-500 meters. Don't make the radius too small (less than 10 m) — GPS can be off by 15-20 meters.
